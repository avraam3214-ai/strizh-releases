# Стриж — сборки

Готовые сборки прокси-клиента: APK для Android и архив для Windows.
Исходники сюда не выкладываются, они лежат отдельно.

Файлы — во вкладке [Releases](../../releases).

## Как ставить

**Android** — скачать `strizh-<версия>-arm64.apk` и открыть.
Система спросит разрешение на установку из этого источника.

**Windows** — скачать `strizh-<версия>-windows.zip` и распаковать
поверх прежней папки. Настройки, подписки и правила лежат отдельно,
в профиле пользователя, и при обновлении не теряются.

## Зачем открытый репозиторий

Приложение само проверяет, не вышла ли версия свежее, и берёт сведения
отсюда. Из приватного репозитория скачать файл можно только с ключом, а
ключ, зашитый в приложение, достанет любой, кто получит APK. Поэтому
сборки лежат открыто, а код — нет.
